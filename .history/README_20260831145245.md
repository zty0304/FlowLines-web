# SIGGRAPH Asia Project Page Template

This folder contains a clean, responsive GitHub Pages landing page template for a SIGGRAPH Asia paper.

## Quick start

1. Open `index.html` in a browser to preview locally.
2. Replace the placeholder title, author list, affiliations, and links.
3. Upload this folder to a GitHub repository.
4. Enable GitHub Pages in the repository settings.

## GitHub Pages notes

- If the repository is named `username.github.io`, the site will be published at:
  `https://username.github.io/`
- Otherwise, use a project repository and publish from the `main` branch or the `docs` folder.

## Recommended edits

- Change the paper title in `index.html`
- Update the abstract and key contributions
- Replace sample links with your actual PDF, video, and code URLs
- Add your real team information and institution names
- Swap in your own teaser image, diagrams, or screenshots

## Example structure

- `index.html` — page content
- `styles.css` — theme and responsiveness
- `script.js` — small enhancement script

This template is intentionally simple and easy to adapt for an academic project page.
